# HW2
Задание №2 курса Data Science

Создать модуль для работы с данными
Создать для вашего модуля методы для обработки данных. Например, визуализация, поиск и заполнение пустых значений, вывода отчетов и т.д.
Датасет выбрать самостоятельно исходя из интересов

Использованный в работе датасет: Anxiety and Depression Mental Health Factors
Датасет содержит информацию ментальном здоровье опрошенных, а также о разнообразных факторах, которые могут влиять на него.
Датасет содержит данные, которые могут быть объединены по следующим категориям:

Demographics: Age, Gender, Education, Employment Status

Lifestyle Factors: Sleep Hours, Physical Activity, Social Support

Mental Health Metrics: Anxiety Score, Depression Score, Stress Level

Medical History: Family History of Mental Illness, Chronic Illnesses, Medication Use

Coping Strategies: Therapy, Meditation, Substance Use

Additional Factors: Financial Stress, Work Stress, Self-Esteem, Life Satisfaction, Loneliness


Анализ датасета показал, что ни один из примененных методов не может позволить предсказывать уровень стресса респондента с вероятностью ощутимо выше случайного выбора значения.
Наиболее вероятной причиной является то, что большинство параметров являются субъективными оценочными суждениями респондентов о собственном состоянии, которые с высокой вероятностью содержат значительные искажения, не позволяющие выявить закономерности или уверенно использовать их обученной моделью
